# Demonstration limitations

- Data persists only in the current browser and Admin Reset restores it.
- Role selectors are not authenticated accounts.
- Images are not durably stored or processed by computer vision.
- Confidence and purity are controlled outputs with manual correction.
- Prices are fictional but plausible indicative demo data, version 2026.08-demo; not live, certified or binding.
- Company names are fictional and not licensed partners.
- Payment is represented; no money moves.
- Environmental impact is indicative, not certified.
