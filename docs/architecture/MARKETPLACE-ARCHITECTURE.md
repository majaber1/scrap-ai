# Marketplace Architecture

V1 loop remains: open listing, buyer offer, seller accept (one winner), pickup.

V2 domain must allow without rewrite: listing, offer, RFQ, open auction, sealed bid, recurring contract, sourcing request.

State machines: see STATE-MACHINES.md. Implementation of extra modes starts Phase 2–8, not Phase 0.

Matching is a separate intelligence capability (Phase 2+).
